# BidSpot

BidSpot is a global local-business sponsored-ranking marketplace. Businesses compete for transparent sponsored placement within a specific country, region, city, and category while visitors can still review useful business information such as address, ratings, services, hours, verification status, and availability.

## Production stack

- Next.js
- Vercel
- Supabase
- Stripe
- Resend

## Core product principles

- Sponsored rank is always clearly labeled.
- A higher bid improves sponsored placement; it does not imply objective quality.
- Business profiles include country, region/state, city, postal code, full address, service area, website, phone, hours, services, verification state, and review signals.
- Visitors can browse and filter rankings globally by country, region, city, and category.
- Businesses can claim profiles, manage locations, place bids, and review bid/payment history.
